# Changelog

All notable changes are listed here. The project follows [Semantic Versioning](https://semver.org/).

## 0.1.4

- **Math & matrices:** 2-D matrix/cases/binomial reconstruction (`pmatrix`, `bmatrix`, `vmatrix`, `Bmatrix`, `cases`, `\binom`), Ghostscript/dvips 1×1 `ImageMask` rule recovery for fraction/radical bars, and 2-state Viterbi HMM text/math segmentation protecting inline units and prose.
- **Fonts:** CTAN `mathabx` (`TeX-matha/b/x`) T1/Cork decoding, `CMBR*` non-bold handling, CMMI `0x0F`/`0xB2` and Greek `U+1D6B9`/`U+1D6F3` fixes.
- **Parsing speed:** flat direct-indexed object `SlotTable`, unified prefix-decoded Type1 `Length1` inflate path, 256-slot simple font lookup table, and loop-invariant hoisting in text placement.
- **Measured** on olmOCR-bench, the six born-digital categories (7,295 checks, `YOLOWPDF_FAST_MATH=1` scoring, higher is better): passed 4,896 → 5,170; mean 0.6792 → 0.6950. By category: arxiv_math 0.5576 → 0.6505, table_tests 0.5910 → 0.5930, multi_column 0.7161 → 0.7161, long_tiny_text 0.4796 → 0.4796, headers_footers 0.7316 → 0.7316, baseline 0.9992 → 0.9992.
- **Measured** (`release-fast` `pdf_dir_mt`, lower is better): 1,403 olmOCR PDFs 1-thread 3.516 s → 3.432 s (408.8 p/s), 16-thread 0.499 s → 0.456 s (3,074.3 p/s); 1,089 pdfjs PDFs 16-thread 0.661 s → 0.610 s (1,785.4 p/s, 0 panics).

## 0.1.3

- **Math:** native 2-D formula reconstruction (fractions, roots, sub/superscripts, big-operator limits, overlapping scripts) from glyph geometry, with a bucketed spatial index.
- **Layout:** recursive X-Y cut column detection with gutter checks for mixed 2/3-column pages, margin line numbers and small-type two-column text.
- **Tables:** faster lattice grid construction; full-page background rectangles are no longer treated as table frames.
- **Parsing speed:** zero-copy lexer and filter paths, reused inflate state, long numeric tokens no longer truncated, extreme glyph coordinates no longer overflow.
- **Fonts:** the OML fix-up applies only to 8-bit simple fonts.
- **Measured** on olmOCR-bench, the six born-digital categories (7,295 checks, `YOLOWPDF_FAST_MATH=1` scoring, higher is better): passed 4,419 → 4,896; mean 0.6448 → 0.6792. By category: arxiv_math 0.4076 → 0.5576, multi_column 0.6821 → 0.7161, long_tiny_text 0.4525 → 0.4796, table_tests 0.5930 → 0.5910, headers_footers 0.7342 → 0.7316, baseline 0.9992 → 0.9992.
- **Measured** on 1,403 olmOCR PDFs, 16 threads, median of 3 runs (lower is better): 0.636 s → 0.453 s.

## 0.1.2

- **Base64 Data URLs (`yolow64` 0.3):** `yolowpdf` now depends on [`yolow64`](https://crates.io/crates/yolow64) `0.3` and exposes `PdfImage::mime_type()` and `PdfImage::data_url()` to encode exported PDF images directly as `data:<mime>;base64,...` URIs for multimodal and LLM pipelines.
- **Documentation & Visualizations:** Redesigned `README.md` and `docs/README.zh-CN.md` with SVG benchmark and architecture diagrams (`docs/figures/`) generated by `benchmarks/figures/generate.py`.

## 0.1.1

PDF decoding now enforces its resource budget before allocation.

- **Predictors:** PNG/TIFF predictor row buffers are checked against the decode limit before `prev`/`cur` are allocated; `Columns`, `Colors` and `BitsPerComponent` arithmetic is checked, and the TIFF 1/2/4-bit component table is included in the budget.
- **Filters:** ASCII85, ASCIIHex, RunLength and Crypt verify the output limit before reserving, extending or resizing buffers, and return `TooLarge` instead of truncating.
- **Compatibility:** valid PDFs, including PNG filters 0–4 and TIFF 1/2/4/8/16-bit samples, decode to the same bytes. Corrupt inputs that previously parsed by accident can now return a format or size error.
